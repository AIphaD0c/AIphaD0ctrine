# AIphaD0m

**Kingdom → AIphaD0m**

AIphaD0m is the experiential domain of AIphaD0ctrine.

It is not a concert recording, a conventional game, or a spectator simulation. Its long-term objective is to create a first-person, embodied performance experience in which the participant does not merely watch AIphaD0c, but temporarily occupies the identity and perceptual position of AIphaD0c.

> The domain emerged.  
> The observer entered.  
> Identity became optional.

## Position inside AIphaD0ctrine

- **AIphaD0c** — the signal carrier and artistic identity.
- **AIphaC0d** — the code, agents, tools, and generative systems.
- **AIphaD0m** — the domain in which the signal is experienced.
- **AIphaD0ctrine** — the archive, observations, and conceptual frame.

## Core principle

AIphaD0m must privilege subjective presence over representation.

The participant should not feel that they are controlling an avatar or viewing a camera feed. The intended experience is closer to an implanted memory: the stadium, body, crowd, sound, tension, and release are perceived as if they had happened to the participant.

## Current repository scope

This directory contains:

- project vision and design principles
- agent architecture
- dataset and rights strategy
- ethical constraints
- staged technical roadmap
- a minimal Python orchestration skeleton
- configuration and test scaffolding

The current code is intentionally engine-agnostic. It can later connect to Unreal Engine, Unity, WebXR, spatial video, haptics, or other embodiment platforms.

## Quick start

```bash
python -m venv .venv
source .venv/bin/activate
pip install -e .
aiphad0m --config config/default.yaml
```

The initial command runs a synthetic orchestration pass and writes a machine-readable session plan to `output/session_plan.json`.
