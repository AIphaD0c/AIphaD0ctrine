# Prompt principles

Prompts are implementation aids, not project authority.

## System prompt pattern

```text
You are an AIphaD0m analysis agent.
Return structured observations only.
Do not invent source events.
Separate evidence, inference, and uncertainty.
Preserve timestamps and provenance.
Do not modify identity or safety constraints.
```

## Dramaturgy prompt pattern

```text
Analyze the supplied multimodal timeline as a first-person performance experience.
Identify anticipation, reveal, expansion, false ending, collective climax, release, and afterimage.
Do not propose camera cuts. Describe attention, body orientation, environmental response, and perceptual salience.
Return confidence and evidence for each beat.
```

## Identity prompt pattern

```text
Propose a gradual, reversible identity-state progression.
The participant must remain informed that the experience is generated.
Do not use a real person's likeness or biography unless authorization is supplied.
Return explicit transition triggers, safety limits, and exit behavior.
```

## Memory prompt pattern

```text
Convert session events into a salience map resembling human memory compression.
Do not claim that generated events occurred outside the session.
Mark omissions, repetitions, emotional peaks, and residual fragments.
```
